# 📰 News Article Summarization using Seq2Seq with Attention

## 📌 Overview
This project implements an abstractive News Article Summarization model using a Seq2Seq LSTM architecture with Bahdanau Attention. The model is trained on the CNN/DailyMail dataset to generate concise summaries from long news articles.

## 🚀 Features
- Text preprocessing and cleaning
- Tokenization and sequence padding
- Seq2Seq LSTM Encoder-Decoder
- Bahdanau Attention Mechanism
- Automatic abstractive summary generation
- TensorFlow/Keras implementation

## 🛠️ Tech Stack
- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- NLTK

## 📂 Dataset
- CNN/DailyMail News Dataset

## 📊 Model Details
- Embedding Dimension: 128
- LSTM Hidden Units: 256
- Max Article Length: 250
- Max Summary Length: 40
- Optimizer: Adam
- Loss: Sparse Categorical Crossentropy

## ▶️ How to Run
1. Install required libraries.
2. Download the CNN/DailyMail dataset.
3. Update the dataset path in the notebook.
4. Run all notebook cells.
5. Train the model and generate summaries.
